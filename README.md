# HR-Analytics-Power-BI

# 📊 Project Overview

This project is an interactive HR Analytics Dashboard developed using Microsoft Power BI.

The dashboard provides insights into employee attrition, workforce demographics, job roles, salary slabs, education, experience, gender, and department-wise employee distribution.

The objective of this project is to transform HR data into an interactive dashboard that makes workforce analysis easier and more understandable.

---

# 🎯 Project Objectives

- Analyze total employees and active employees
- Analyze employee attrition
- Calculate attrition rate
- Analyze employee demographics
- Analyze employee age groups
- Analyze job roles and job satisfaction
- Analyze salary slabs
- Analyze education levels
- Analyze employee experience
- Compare employees across departments

---

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX

---

# 🧹 Data Preparation

Power Query was used to prepare the dataset before creating the dashboard.

Data preparation included:

- Data type checking
- Data cleaning
- Handling missing values
- Creating age groups
- Creating salary slabs
- Creating experience groups
- Data transformation

---

# 📐 DAX

DAX measures were created to calculate important HR metrics such as:

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Salary
- Average Experience

---

# 📊 Dashboard Features

The dashboard includes:
- KPI Cards
- Department Filter
- Age Group Analysis
- Salary Slab Analysis
- Job Role & Job Satisfaction Analysis
- Department-wise Employee Count
- Gender Analysis
- Years of Experience Analysis
- Education Analysis
